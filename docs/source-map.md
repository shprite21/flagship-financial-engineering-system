The six supplemental labs retain their own environment and command-line entry points. The four flagship workbenches run in the terminal's shared process and use its normal research queue. The GitHub profile website and the PC recovery backup were inventoried as a website and a duplicate archive. Neither supplies an additional financial model. The research reports retain aggregate results and data fingerprints. Raw vendor history, account databases, broker credentials and the personal résumé stay outside repository history.
